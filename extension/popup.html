Gemini Chrome Bridge

Relays this logged-in tab to the gemini-web-api OpenAI endpoint (chrome backend).

  1. Run the server: GEMINI_BACKEND=chrome uv run gemini-web-api
  2. Keep a gemini.google.com tab open.
  3. Point clients at http://localhost:8100/v1

Check localhost:8100/health — extension_connected should be true.
